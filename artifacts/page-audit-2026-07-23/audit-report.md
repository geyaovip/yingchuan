## UX 与可访问性检查

- 官网和两个登录入口具备清晰标题、主要操作和键盘可识别表单标签。
- 登录页在 1440px 和 390px 下没有裁切、横向滚动或按钮溢出。
- 应用壳提供跳到主要内容、移动端导航焦点约束、退出登录入口。
- 应用导航、状态徽标和移动菜单使用同一图标组件，并保留文本标签或可访问名称。
- 用户端和管理端指标区具有稳定容器、标签和值的视觉层级，不再依赖裸文本排布。
- 数据表在查询结果为空时显示“暂无数据”，避免空白表格被误认为加载失败。
- 数据页统一覆盖加载、空、失败和不可用状态；危险操作提供对象和影响说明。
- 截图只能确认可见结构和布局，不能单独证明完整 WCAG 合规；键盘顺序、读屏器朗读和对比度仍需专项测试。

## 证据限制

本次没有向任何邮箱发送验证码，因此登录后的线上私有页面没有被冒充为“线上视觉已验收”。这些页面的结论来自真实 API 绑定检查、既有集成测试、新增正式路由测试、全仓类型检查和生产构建。上线前仍应由有权限账号完成一次登录后的线上视觉 smoke。
