# 数据洞察与优化闭环验收

验收日期：2026-10-13。范围：E12-S1/S2/S3。

## 本地功能与数据验证

- `npm run check` 通过：格式、lint、类型检查、单元/数据库集成测试、构建、OpenAPI 一致性、文档、密钥扫描。
- API 集成测试 40 项通过，其中分析与新增监测闭环文件 7 项；分析包单元测试 10 项通过。
- 新增数据库迁移覆盖监测计划、执行记录、优化任务、复测关联及时间/费用/尝试次数约束。
- 真实数据库流程验证：所选问题/模型、费用准入、并发执行幂等、暂停、计划修改的乐观锁、租约恢复、三次失败进死信、一次站内通知、工作区隔离与权限撤销。
- 复测验证：问题编辑后仍使用原始版本；重复请求仅创建一次分析；正式且完整的相同条件样本可返回评分差值，诊断样本不宣称效果提升。

## 浏览器验证

Playwright 连接真实本地 API 与测试数据库，页面未使用静态假数据。模型适配器在测试环境返回受控回答，40 条样本经过正式分析、解析、评分、报告服务落库；这不代表本轮调用了生产模型供应商。

- 桌面 1440px、手机 390px 和 320px 检查。
- 已操作：统计时间切换、引用域名/文章切换、引用证据定位对应回答、周监测费用确认/创建/暂停/编辑保存、任务状态与措施保存、复测费用确认/取消。
- 320px 引用和监测页面通过 `documentElement.scrollWidth <= innerWidth` 检查。
- 空项目展示真实空状态；503 错误使用浏览器故障注入验证错误与重试，再恢复真实 API。
- 修正趋势卡内边距、明确排名的说明换行和移动端按钮换行。

## 能力边界

所有自动分析继续经火山方舟 Model Gateway 执行；联网只使用模型内置能力。复测并不自动代表优化有效。自动发布、外部搜索、消费端 AI 页面采集未纳入本次范围。生产数据与真实客户使用验收由后续客户操作确认。
